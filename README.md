# autenticacao-service

Serviço de autenticação da oficina: login de staff e JWT de cliente (RS256), com JWKS para os demais serviços validarem a assinatura. O documento do cliente é consultado no administrativo.

Stack: .NET 8 e Firestore (database nomeado). Org [fiap-vcosta](https://github.com/fiap-vcosta).

Requisitos: [docs/01_requisitos.md](docs/01_requisitos.md).
